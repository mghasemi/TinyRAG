TinyRAG is a lightweight, portable Retrieval-Augmented Generation toolkit designed to run locally on constrained hardware with minimal dependencies.
- Implement a lightweight vector indexer under 1500 lines of code using mainly standard libraries
- Enable one-command document ingestion from PDFs, Markdown, and plain text directories
- Support for LLMs through a standard OpenAI API, using a token
- Provide a CLI interface for real-time query retrieval and response generation.
- Design a simple and modern-looking UI that provides interfaces for document ingestion, browsing ingested documents, and QA.
